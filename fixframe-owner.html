Make an unlock code

After 10 video exports the app shows a request number. Paste the message you received, or type the number.

The three parts are: invitation number, day and month, year and hour.

Unlock code

Copying a code adds it to the log, so you can see later who asked and how often.

This does not look like a request number. It has three groups of digits, for example 07-1011-2615.

Work it out without this tool (phone calculator)
  1. Take the request number, for example 07-1011-2615: invitation 7, day+month 1011, year+hour 2615.
  2. Add the two 4-digit groups: 1011 + 2615 = 3626.
  3. Add the invitation number to your owner number: 1037 + 7 = 1044.
  4. Multiply both results: 3626 × 1044 = 3785544.
  5. Keep the last four digits (5544) and write your owner number behind them: 5544-1037.

Invitation codes

Each code activates the app. Write down who gets which code: the number in front is the invitation number that shows up in every unlock request.

Settings

These values go into access.json. After a change, upload the new access.json to GitHub.

Put access.json on GitHub
  1. Download access.json here.
  2. Open your Fixframe repository on github.com, choose Add file → Upload files, drop access.json and commit. It replaces the old one.
  3. Phones pick up the new list at their next check (see the setting above), when the app is opened with a connection. A phone entering a code reads it at once. GitHub can take a few minutes.

To open the app for everyone again, delete access.json from the repository.
